# v0.1.2 の公開結果と OBS Forum の承認待ち

確認日: 2026-09-20

## 結果

GitHub の [PR #4](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/pull/4)を `main` にマージし、[v0.1.2 Release](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/releases/tag/v0.1.2)で Windows x64 用 ZIP を公開した。OBS Forum には v0.1.2 の版、更新文、概要の日英修正、ZIP の外部ダウンロード URL を保存した。ただし、Forum の更新文にはモデレーター承認待ちと表示され、リソースの見出しは 0.1.1 のままである。一般訪問者に対する v0.1.2 の表示は未確認である。

## GitHub の確認結果

- PR #4 はマージコミット `70d74fb8a9a38ad1eb5278ef63b4983e5531249a` で `main` に取り込まれた。元の作業コミット `0efa9c09f18af53d67afe70e7abb3076eed6b301` は `main` の祖先である。
- PR の [Actions #35480436081](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/actions/runs/35480436081)は、2 回目の試行で clang-format、gersemi、macOS・Windows・Ubuntu ビルドがすべて成功した。初回の clang-format ジョブは依存導入時の `Broken pipe` で失敗したが、コードや CI 設定を変更せずに再実行で成功した。警告にあった Homebrew の tap 信頼設定との因果は確定していない。
- マージ後の `main` の [Actions #35481026159](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/actions/runs/35481026159)は整形検査と 3 OS のビルドに成功した。タグ `v0.1.2` の [Actions #35481183327](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/actions/runs/35481183327)も 3 OS のビルドに成功した。
- `v0.1.2` タグは ZIP の生成元 `0efa9c09f18af53d67afe70e7abb3076eed6b301` を指す。Release は公開済みで、添付ファイルは [`loudness-balance-monitor-0.1.2-windows-x64.zip`](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/releases/download/v0.1.2/loudness-balance-monitor-0.1.2-windows-x64.zip)の 1 件、876,385 バイトである。GitHub の asset digest とローカルファイルの SHA-256 はともに `34F812DC2FF38EEED6C5A4BF755850D468D854270A481758DEBE3D4CBC682B31` だった。

## OBS Forum の確認結果

[Loudness Balance Monitor](https://obsproject.com/forum/resources/loudness-balance-monitor.2327/)で、所有者 `AllegroMoltoV` のログイン状態を確認して操作した。版履歴には 0.1.2 が追加され、[更新文](https://obsproject.com/forum/resources/loudness-balance-monitor.2327/update/8584/)には変更点、Windows OBS 32.1.2 での検証範囲、macOS 実機未確認、インストール先、ドックの手動表示を記載した。保存後の画面には、更新文はモデレーター承認待ちで一般訪問者には非表示と表示された。

リソース概要の日本語・英語にある版番号、ZIP 名、全変更履歴リンクを v0.1.2 に変更した。両言語の Windows 手順に、ポータブル版の確認済み配置とドックの手動表示を追加した。保存後の所有者画面で既存の画像、表、説明と追加文を確認した。リソース編集画面の独立した外部ダウンロード URL は、公開済み ZIP の直リンクに保存された。一方、リソースの見出しは 0.1.1 のままであり、上部のダウンロードボタンが一般訪問者に v0.1.2 を渡すことは確認できていない。
