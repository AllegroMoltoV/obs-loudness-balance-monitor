確認日: 2026-09-20

## 結果

[PR #6](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/pull/6)を `main` に取り込み、[v0.1.3 Release](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/releases/tag/v0.1.3)で Windows x64 用 ZIP を公開した。配布 ZIP 内の DLL を隔離した OBS 32.1.2 に配置し、ドックの表示・非表示の復元と音声表示を確認した。

## OBS 実機確認

検証用 WAV と保存済み設定のある Windows ポータブル版 OBS 32.1.2 を隔離環境で起動した。利用者は、v0.1.3 DLL への交換後もドックと保存済みの声・BGM 選択が表示され、声・BGM・ミックスの数値が動くことを確認した。次に、ドックをメニューから非表示にして正常終了し、再起動時も非表示であることを確認した。再表示すると数値が再び動き、正常終了した。

OBS ログ `2026-09-20 13-05-19.txt`、`13-14-10.txt`、`13-14-26.txt` は `.tmp/issue-2-portable/obs-32.1.2/config/obs-studio/logs` にある。いずれもプラグイン版 `0.1.3` の読み込み、ドック登録と保存済み `DockState` の復元、プラグインのアンロード、メモリーリーク数 0 を記録した。画面上の表示・非表示と音声値の確認は利用者からの報告に基づく。macOS・Linux の OBS 実機、別のサードパーティ製ドックとの組合せは未確認である。
