# macOS 26 ビルド検証の結果

検証日: 2026-09-19

## 実行条件

- 対象: `issue/1-2-validation` のコミット `bf84a9591fc0ed97a091f7e495b0476bb73dd324`
- 実行: [GitHub Actions #35431053665](https://github.com/AllegroMoltoV/obs-loudness-balance-monitor/actions/runs/35431053665)
- macOS ジョブ: `macos-26`、Xcode 26.2、macOS 26.2 SDK、署名なし
- 依存構成: `buildspec.json` が指定する OBS 31.1.1 と 2025-07-11 版 OBS/Qt 依存パッケージ

## 結果

最初の実行では Windows と Ubuntu のジョブが成功し、macOS ジョブは `Build Plugin` で失敗しました。失敗した macOS ジョブを指定してデバッグ再実行したところ、GitHub Actions は Windows と Ubuntu も再実行しました。macOS は同じ箇所で失敗し、Windows と Ubuntu は再度成功しました。

macOS の最初の失敗は、CMake が生成した AutoMoc の事前処理コマンドです。`clang++` は `conflicting deployment targets, both '26.2' and '26.2' are present in environment` と `both '26.2' and '25.2'` を出して終了しました。デバッグログで確認できる AutoMoc の `clang++ -std=c++17 -w -dM -E ...` コマンドには、配置ターゲットを指定する引数は見当たりません。リポジトリのプラグイン本体のコンパイルとリンクには到達していません。

この結果から、issue #1 の `framework 'AGL' not found` を再現したとも、解消したとも判断できません。また、今回の依存構成は報告された OBS 32.0.4 の構成ではありません。

## 原因について分かる範囲

[Clang の Darwin 向けドライバー実装](https://clang.llvm.org/doxygen/Darwin_8cpp_source.html)は、複数の `*_DEPLOYMENT_TARGET` 環境変数が同時に設定されると、この診断を出します。今回のログは各環境変数の名前と値を記録していないため、どの変数が設定されていたかは未確認です。デバッグログの事前処理コマンドに配置ターゲット引数がないことは、環境変数の競合という説明と整合しますが、設定元までは特定できません。

## 次の検証

macOS ジョブ内で AutoMoc が継承する配置ターゲット環境変数を記録し、競合だけを除いた状態で再実行します。ビルドがリンクまで進んだら `AGL` 参照の有無を確認します。OBS 32 系依存構成の検証と OBS 実機での動作確認は、その後に分けて扱います。
